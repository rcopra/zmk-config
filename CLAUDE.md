# CLAUDE.md

Quick orientation for agents working in this `zmk-config` repository. The
operative authoring rules are in [AGENTS.md](AGENTS.md); the canonical keymap
map is in [docs/d50-map.md](docs/d50-map.md). Read those before editing.

## What this is

A personal [ZMK](https://zmk.dev) configuration based on
[urob's zmk-config](https://github.com/urob/zmk-config), pinned through
`config/west.yml` and `flake.lock` (ZMK 0.4-era main, Zephyr 4.1, HWMv2 board
names). The owner is a fullstack web developer on
macOS/Linux (no Windows) who types Colemak-DH and expects macOS-style
shortcuts.

- **Primary board: Hillside D50** (50 keys, split, optional Prospector dongle
  running Carrefinho's status screens — see
  [docs/prospector-dongle.md](docs/prospector-dongle.md)). Entry point:
  `config/hillside_d50.keymap` → `config/base.keymap`.
- **Legacy/fallback: Temper** (36 keys). Kept building.
- Other keymaps (`glove80`, `corneish_zen`, `planck_rev6`) are historical
  samples inherited from upstream; do not treat them as current.

## Keymap at a glance

- Layers: `DEF 0`, `GAME 1`, `NAV 2`, `FN 3`, `NUM 4`, `SYS 5`, `MOUSE 6`
  (`config/base.keymap:16-22`).
- Homerow mods: left `A R S T` = Ctrl/Alt/Cmd/Shift; right `N E I O` =
  Shift/Cmd/Alt/Ctrl. Timing is intentionally tuned; do not change it.
- Thumbs: outer-left tap Space / hold NAV, middle-left tap Enter / hold FN;
  right thumbs Space, Smart Num (tap num-word, double-tap sticky NUM, hold
  NUM), Magic Shift (tap sticky Shift, hold Shift, double-tap caps-word).
- D50 extras: outer pinky columns, raised Hyper-3 keys (`Ctrl+Opt+Cmd`), upper
  thumbs for tmux prefix (`Ctrl+A`) and dongle-screen keys.
- Symbols live in combos (`config/combos.dtsi`); leader sequences
  (`config/leader.dtsi`) handle umlauts and system actions.

Physical keys are addressed with shared aliases (`L_COL1_TOP` … `R_COL6_BOT`,
plus cluster names) defined in `config/key-labels/hillside_d50.h`; the
exhaustive position card is `draw/hillside_d50-positions.md` (generated by
`just draw-d50`); `docs/hillside50dactyl-annotated.png` stamps the same
numbers onto the board photo.

Full layer/behavior/combo tables: [docs/d50-map.md](docs/d50-map.md).

## Commands

```bash
just init                        # first-time west workspace setup
just list                        # build targets
just build hillside              # all Hillside D50 targets
just build hillside_d50_dongle   # dongle firmware only
just build temper                # legacy Temper targets
just draw                        # 34-key base visualization
just draw-d50                    # D50 map + positions card
just layout-card                 # D50 positions card only
just clean                       # remove build + firmware artifacts
```

Run inside `nix develop` (or let `direnv` load it). CI mirrors `just init`,
`just build settings_reset`, `just draw`, and `just draw-d50`.

## Cross-repo link

This repo owns the physical → emitted half of the interaction model. The
emitted → handler half (OmniWM, Karabiner, Ghostty, tmux, zsh, Neovim) lives in
the dotfiles chezmoi repo:

- `~/.local/share/chezmoi/AGENTS.md` — navigation ethos, workflow map, laptop parity.
- `~/.local/share/chezmoi/home/dot_config/...` — handler configs (Karabiner, OmniWM, Ghostty).
- `~/.local/share/chezmoi/home/dot_tmux.conf` — tmux prefix and panes.

When a change alters an emitted chord, check the handler side; when planning a
new shortcut, trace physical key/layer → emitted chord → interceptor → app and
pick a single owner.
