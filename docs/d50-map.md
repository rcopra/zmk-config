# Hillside D50 Keymap Map

Canonical, agent-oriented map of the physical Hillside D50 keymap. The D50 is
the daily driver; Temper is retained as a legacy/fallback board (see
[prospector-dongle.md](prospector-dongle.md)). This document describes the
physical → emitted half of the interaction model. The emitted → handler half
(OmniWM, Karabiner, Ghostty, tmux, zsh, Neovim) lives in the dotfiles repo:
`~/.local/share/chezmoi/AGENTS.md`.

Authoring rules and macro conventions live in [`../AGENTS.md`](../AGENTS.md).
Do not retune homerow-mod timing without an explicit request.

## Hardware and build targets

50 keys = the 34-key core handled by `base.keymap` + 16 D50 extras defined in
`hillside_d50.keymap`.

| Mode | Boards | Targets |
| --- | --- | --- |
| Standalone split | 2× nice_nano@2.0.0//zmk | `hillside_d50_left`, `hillside_d50_right` |
| Dongle split (parked) | XIAO BLE central + 2× nice_nano peripherals | `hillside_d50_left_dongle`, `hillside_d50_right_dongle` |

The dongle runs the keymap as BLE central; both halves bond to it. The central
dongle targets are parked while the Prospector dongle is overhauled for ZMK
4.1: YADS does not build there, and is being replaced by Carrefinho's
`prospector-zmk-module` status screens. The history (and the half-side
peripheral targets) are documented in
[prospector-dongle.md](prospector-dongle.md).

## Physical layout

```
       left half                                          right half
  col: 1    2    3    4    5    6                 6    5    4    3    2    1
      X_LT LT4 LT3 LT2 LT1 LT0                    RT0 RT1 RT2 RT3 RT4 X_RT
      X_LM LM4 LM3 LM2 LM1 LM0                    RM0 RM1 RM2 RM3 RM4 X_RM
      X_LB LB4 LB3 LB2 LB1 LB0                    RB0 RB1 RB2 RB3 RB4 X_RB
          X_LR      X_LU  (upper thumb)  X_RU      X_RR
              X_LH LH1 LH0                RH0 RH1 X_RH
```

Column numbering is mirrored: col 1 is the outer pinky on both hands, and
columns count inward to col 6 at the inner index. The right half therefore
reads 6 → 1 left-to-right in the picture above.

Positions 0–49 are assigned by `config/boards/shields/hillside_d50/hillside_d50-layouts.dtsi`
(used by `just draw-d50`) and are consistent with the matrix transform. Label
definitions are in `config/key-labels/hillside_d50.h`.

QMK/Colemak-DH letters for the 34 core keys (Base layer):

```
  Q W F P B      J L U Y '
  A R S T G      M N E I O
  Z X C D V      K H , . ?
```

### Shared physical vocabulary

Use these names in conversation, docs, and new code. The aliases are defined
in `config/key-labels/hillside_d50.h`; the `LT*`/`X_*` labels and 0-49
positions remain the machine-facing canonical names for combos, draw, and CI.

| Alias pattern | Physical location |
| --- | --- |
| `L_COL1_*` / `R_COL1_*` | outer pinky column (`X_LT/X_LM/X_LB`, `X_RT/X_RM/X_RB`) |
| `L_COL2_*` / `R_COL2_*` | pinky column (`LT4/LM4/LB4`, `RT4/RM4/RB4`) |
| `L_COL3_*` / `R_COL3_*` | ring column (`LT3/LM3/LB3`, `RT3/RM3/RB3`) |
| `L_COL4_*` / `R_COL4_*` | middle column (`LT2/LM2/LB2`, `RT2/RM2/RB2`) |
| `L_COL5_*` / `R_COL5_*` | index column (`LT1/LM1/LB1`, `RT1/RM1/RB1`) |
| `L_COL6_*` / `R_COL6_*` | inner-index column (`LT0/LM0/LB0`, `RT0/RM0/RB0`) |
| `_TOP` / `_HOME` / `_BOT` | row suffix: top, home (middle), bottom |
| `L_RAISE_OUTER` / `L_RAISE_INNER` | left raised pair |
| `L_THUMB_UPPER_OUTER` / `L_THUMB_UPPER_INNER` | left upper thumb row |
| `L_THUMB_LOWER_OUTER` / `_MID` / `_INNER` | left lower thumb row |
| right mirror | prefix `R_`, same cluster names |

"Left" and "right" are the hand that presses the key, inner/outer is from
that hand's point of view. The exhaustive card is
`draw/hillside_d50-positions.md` with the numbered map at
`draw/hillside_d50-positions.svg` (both generated by `just draw-d50` and
CI-checked). The same numbers and aliases are stamped onto the board photo in
`docs/hillside50dactyl-annotated.png` for physical reference.

The raised-pair keys emit **Hyper-3** (`LC(LA(LGUI))`, i.e. Ctrl+Opt+Cmd). The
laptop equivalent is Caps Lock held via Karabiner, and OmniWM binds its `focus.*`
actions to Hyper-3 + `N/E/U/I` (4-modifier `Hyper+…` adds Shift for `move.*`).

## Layers

Layer IDs are defined in `config/base.keymap:16-22`.

| ID | Name | Activation | Purpose |
| --- | --- | --- | --- |
| 0 | DEF | default | Colemak-DH, homerow mods, combos |
| 1 | GAME | `&tog GAME` on SYS (LM4) | plain QWERTY passthrough; no combos |
| 2 | NAV | hold outer-left thumb (`lt_spc NAV`) | navigation, mods, window/tab switching |
| 3 | FN | hold middle-left thumb (`lt FN RET`) | F-keys, media, dongle screen keys |
| 4 | NUM | `SMART_NUM` (mid-right thumb): tap num-word, dbl-tap sticky, hold | numpad + right-hand mods |
| 5 | SYS | tri-layer FN + NUM (`ZMK_CONDITIONAL_LAYER`) | Bluetooth, GAME toggle, bootloader, reset |
| 6 | MOUSE | `Smart Mouse` combo (F+P) | mouse move/scroll/click; auto-exits via tri-state |

### How D50 layers are assembled

`config/hillside_d50.keymap` defines a local `ZMK_BASE_LAYER(...)` wrapper and
then includes `base.keymap`, which calls it once per layer. The wrapper:

- inserts the outer pinky keys (`X_LT/LM/LB`, `X_RT/RM/RB`),
- inserts the raised pairs and upper thumbs,
- **hardcodes the left bottom thumbs** (`lt_spc NAV`, `lt FN RET`, `&none`) on
  every layer; the `LH` macro argument is ignored,
- writes `&kp SPACE` + `RH` for the right bottom thumbs, so positions 48–49
  follow each layer's `RH` argument while position 47 is always Space.

Consequence: to change a left bottom thumb binding for the D50, edit
`hillside_d50.keymap`, not the per-layer call in `base.keymap`.

## Behaviors

| Behavior | Macro | Parameters | Notes |
| --- | --- | --- | --- |
| `hml` / `hmr` | `MAKE_HRM` | balanced, 225ms tapping-term, 175ms quick-tap, 150ms require-prior-idle, positional + hold-trigger-on-release | Left `A R S T` → Ctrl/Alt/Cmd/Shift; right `N E I O` → Shift/Cmd/Alt/Ctrl |
| `lt` | `&lt` config | balanced, 200ms | used by `lt_spc` and `lt FN RET` |
| `lt_spc` | `ZMK_HOLD_TAP` | balanced, 200ms | tap Space; Shift+tap `. ` + sticky Shift (sentence end); hold NAV |
| `magic_shift` | `ZMK_HOLD_TAP` | balanced, 200ms | tap sticky Shift, Shift+tap/double-tap caps-word, hold Shift |
| `smart_num` / `num_dance` | `ZMK_HOLD_TAP` + `ZMK_TAP_DANCE` | 200ms | tap num-word (auto-exit on non-digits), double-tap sticky NUM, hold NUM |
| `smart_mouse` | `ZMK_TRI_STATE` | ignored layers NAV/FN/MOUSE | toggles MOUSE; exits when a key outside the ignored set is pressed |
| `swapper` | `ZMK_TRI_STATE` | ignores LT2 | Cmd+Tab switcher (NAV) |
| `tab_swapper` / `reverse_tab_swapper` | `ZMK_TRI_STATE` | ignores LB1 / LB2 | Ctrl+Tab / Ctrl+Shift+Tab (NAV) |
| combo HRM shim | `ZMK_COMBO_8` → `hm_combo_*` | — | makes combos over HRMs tap-only; hold variants: `ldr` → LShift+LCtrl, `ldrsh` → LShift+LCtrl+LAlt, `lpar` → RShift+LCtrl, `rpar` → RShift+LAlt |
| `comma_morph` / `dot_morph` | `SIMPLE_MORPH` | Shift, Ctrl+Shift levels | `,`→`;`→`<`; `.`→`:`→`>` |
| `qexcl` | `SIMPLE_MORPH` | Shift | `?` → `!` |
| `lpar_lt` / `rpar_gt` | `SIMPLE_MORPH` | Shift | `(`→`<`, `)`→`>` |
| `caps_word` | `&caps_word` | `ignore-modifiers` deleted | allows mods while active |
| sticky keys | `&sk` / `&sl` | `release-after-ms = 900`, `quick-release`; `&sl` ignores modifiers | `CANCEL` alias (`K_CANCEL`) cancels caps-word/auto-layers |
| `&mt` | `MT_CORE` | tap-preferred, 220ms, hold-trigger position 0 | used by `NAV_*` aliases |

### Dead or unbound definitions

Useful as reclaim candidates; verify before assuming a behavior is reachable:

- `mt_home`, `mt_end`, `masked_home`, `masked_end`, and the `MASK_MODS` macro
  (`base.keymap:90-104`) are defined but never bound in any layer.
- `bs_del` (`base.keymap:194`) is defined but never bound.

(except `bspc`: idle 50ms); vertical combos use term 30ms / idle 50ms. Active

## Leader sequences

Activate with the `ldr` combo (S+T), then type the sequence. Defined in
`config/leader.dtsi`; Shift keys are ignored during the sequence.

| Sequence | Output |
| --- | --- |
| A | `ä` (Unicode, macOS input mode) |
| O | `ö` |
| U | `ü` |
| S | `ß` |
| U S B | switch output to USB |
| B L E | switch output to BLE |
| R E S E T | `sys_reset` |
| B O O T | `bootloader` |

## Emitted global chords

The cross-tool contract; handler configs live in the dotfiles repo.

| Physical origin | Emits | Handler |
| --- | --- | --- |
| Raised pair keys (`X_LR`/`X_RR`) | Hyper-3 = Ctrl+Opt+Cmd | OmniWM `focus.*` on N/E/U/I; add Shift for 4-mod `Hyper+` `move.*` |
| Upper thumbs (`X_LU` 2 / `X_RU` 2) | Ctrl+A | tmux prefix |
| Upper thumb `X_LU` 1 | F24 | Prospector dongle screen (F22–F24 reserved) |
| Upper thumb `X_RU` 1 | KP_DIVIDE | no in-repo consumer; reuse candidate |
| NAV arrows / Backspace / Delete | hold = Cmd+arrow / Opt+BSPC / Opt+DEL | macOS text navigation |
| NAV `A R S T` | sticky Ctrl/Alt/Cmd/Shift | any app |
| NAV `P` / `F` | Cmd+Tab / Shift+Tab | app/window switcher |
| NAV `C` / `D` | Ctrl+Shift+Tab / Ctrl+Tab | tab switching (tmux/editors) |
| FN right hand | media keys, F-keys, Cmd+L | macOS |
| SYS | BT select/clear, GAME toggle, bootloader, reset | firmware |
| Sticky Shift (`magic_shift`, `lt_spc` morph) | one-shot Shift | any app |
| `CANCEL` | `K_CANCEL` | cancels caps-word and auto-layers |

Laptop parity: built-in QWERTY with Caps Lock held as Hyper-3 through Karabiner,
Option as a pure modifier, and Ghostty passing Option through as Alt. See
`~/.local/share/chezmoi/AGENTS.md` for the full navigation tree.

## Regenerate and verify

```bash
just draw-d50                    # map + positions card into draw/
just layout-card                 # positions card only (alias/pos/RC/Base)
just build hillside              # all D50 targets (dongle parked)
just list                        # all build targets
```

CI runs `just build settings_reset`, `just draw`, and `just draw-d50`, then
fails if regeneration changes tracked draw artifacts.
